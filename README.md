# Vehicle Dealership Web Platform

Full-stack vehicle dealership application combining a public inventory experience with administrative management flows.

## Overview

The project was developed for a dealership use case where catalog content needed to be managed dynamically rather than hard-coded into a landing page. It focuses on vehicle publishing, categorization and customer contact from a responsive commercial interface.

## Core capabilities

- Public vehicle catalog
- Administrative inventory workflows
- Vehicle/category management
- Dynamic content backed by application data
- Lead capture and customer contact
- WhatsApp-oriented commercial conversion flows
- Responsive interface built for dealership presentation

## Engineering focus

This repository represents a client-oriented full-stack application and demonstrates CRUD-style business workflows, data-backed content and separation between the public sales experience and administrative operations.
